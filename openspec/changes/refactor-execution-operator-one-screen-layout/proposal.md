# Change: 运维执行界面单屏布局规划

## Why

当前 `/executions` 运维执行页采用自上而下长表单布局（模式选择 → 脚本编辑 → 主机选择 → 执行选项 → 执行按钮 → 执行结果），在常规分辨率下需要多次滚动才能完成配置与查看结果，运维操作不够便捷。将布局规划为**一屏内完整展示**，可减少滚动、提高操作效率。

## What Changes

- **单屏布局**：整页在典型视口（如 1440×900、1920×1080）内不溢出或仅最小化滚动，配置区与结果区同屏可见。
- **配置区与结果区同屏**：执行前可见「模式 + 脚本 + 主机 + 选项 + 执行」；执行后结果与配置同屏展示（如左右分栏或上配置下结果），无需滚出视野即可查看状态与日志。
- **区域高度约束**：脚本编辑区、主机列表等可滚动区域使用最大高度 + 内部滚动，避免撑开整页。
- **响应式**：小屏可降级为上下布局，仍优先保证一屏内关键操作可见。

## Impact

- **受影响规格**：execution-operator（布局相关需求）
- **受影响代码**：`frontend/src/pages/executions/ExecutionOperatorPage.tsx`，以及 `components/operator/` 下各组件样式或布局相关 props（如 ScriptEditor、HostSelector、ExecutionResults 的高度与容器）
