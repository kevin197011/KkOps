# Design: 运维执行界面单屏布局

## Context

运维执行页 (`/executions`) 当前为单栏垂直堆叠：标题、模式选择、脚本编辑、主机选择、执行选项、执行按钮、执行结果依次排列，`Content` 使用 `maxWidth: 1200`、`padding: 24`、`Space size={24}`，在 1080p 及以下常见分辨率下需明显滚动才能看到执行按钮和结果。运维希望「配置 + 执行 + 看结果」在一屏内完成，减少来回滚动。

## Goals / Non-Goals

### Goals
- 在典型视口（如 1440×900、1920×1080）内，主要操作与执行结果同屏可见。
- 配置区（模式、脚本、主机、选项、执行按钮）与结果区布局清晰，执行后无需滚出视野即可查看状态和日志。
- 脚本区、主机列表等长内容使用固定/最大高度 + 内部滚动，不撑破一屏。

### Non-Goals
- 不改变现有执行流程、API 与权限。
- 不要求所有分辨率零滚动，仅要求典型桌面分辨率下一屏为主。

## Decisions

### 1. 整体布局形态

**方案 A：左右分栏（选用）**
- 左侧：配置区（模式 + 脚本 + 主机 + 选项 + 执行按钮），固定或最大宽度，内部各块使用 max-height + overflow。
- 右侧：执行结果区，执行前可为空或占位，执行后展示状态与日志。
- 一屏内左侧配置、右侧结果同时可见，便于执行后立刻查看。

**方案 B：上配置下结果**
- 上半屏：紧凑配置区（可考虑模式+选项同一行等）。
- 下半屏：脚本 + 主机 + 执行按钮 与 结果区 共享或切换。
- 通过严格 max-height 控制上半屏高度，保证结果区在一屏内。

**方案 C：保持当前单栏，仅做高度约束**
- 脚本区、主机区设 max-height + overflow，整页仍单栏，通过缩短各块高度减少滚动。

**决策**：优先方案 A（左右分栏），配置与结果同屏最符合「一屏操作便捷」；若实现成本或响应式考虑更倾向方案 B，可在 tasks 中选用上配置下结果并明确高度分配。

### 2. 视口与高度分配

- 页面根容器使用 `minHeight: calc(100vh - <header 等占位>)`，保证一屏高度可用。
- 左侧配置区：宽度约 400–520px（或 flex 比例），内部：
  - 模式选择、执行选项：不设固定高度。
  - 脚本编辑：`maxHeight: 200px`（或 20vh），内部滚动。
  - 主机选择：`maxHeight: 220px`（或 24vh），列表内部滚动。
- 右侧结果区：`flex: 1`，最小宽度约 360px；内部结果列表/日志使用 `overflow: auto`，占满右侧剩余高度。

### 3. 响应式

- 宽度小于某断点（如 992px）：改为上下布局，上方为配置区（可折叠或保持紧凑），下方为结果区；仍通过 max-height 控制配置区高度，使结果区尽量同屏可见。

### 4. 组件改动范围

- **ExecutionOperatorPage**：由单栏 `Space direction="vertical"` 改为 `Row`/`Col` 或 Flex 左右（或上下）分栏；根布局使用 viewport 高度。
- **ScriptEditor**：接受可选的 `maxHeight` 或 `style`，外层 `Card` 或内容区设置 `overflow: auto`。
- **HostSelector**：主机列表容器设置 `maxHeight` + `overflow: auto`。
- **ExecutionResults**：容器占满右侧（或下半屏），内部已有滚动则保持，确保不撑开整页。

## Risks / Trade-offs

| 风险 | 缓解 |
|------|------|
| 小屏下左右栏过窄 | 断点以下改为上下布局，并保证配置区可折叠或紧凑 |
| 脚本/主机区过小 | 使用 vh 或合理 min-height，保证至少 160–200px 可视高度 |

## Migration Plan

1. 在 ExecutionOperatorPage 中引入分栏布局与 viewport 高度。
2. 为 ScriptEditor、HostSelector 增加高度约束与内部滚动。
3. 将 ExecutionResults 放入右侧（或下方）固定区域。
4. 增加断点，小屏切换为上下布局。
5. 手动在不同分辨率下验证一屏可见与操作流畅。

## Open Questions

- 左侧配置区是否需要在窄屏下可折叠（Collapse），以进一步压缩高度？
- 是否统一使用 992px 作为左右/上下切换断点（与 Ant Design 的 lg 一致）？
