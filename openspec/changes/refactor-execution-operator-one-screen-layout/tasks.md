# Tasks: 运维执行界面单屏布局

## 1. 布局骨架

- [x] 1.1 在 `ExecutionOperatorPage` 中改用 viewport 高度容器（如 `minHeight: calc(100vh - 120px)`）
- [x] 1.2 使用 Flex 或 Grid/Row-Col 实现左右分栏：左侧配置区，右侧结果区
- [x] 1.3 设定左侧宽度（如 420–520px 或比例）与右侧 `flex: 1`，保证结果区有最小宽度（如 360px）
- [x] 1.4 在宽度 &lt; 992px 时切换为上下分栏（上配置、下结果），保持一屏内可见

## 2. 配置区高度约束

- [x] 2.1 为 `ScriptEditor` 增加可配置的 `maxHeight`（如 200px 或 20vh）及内部滚动（`overflow: auto`）
- [x] 2.2 为 `HostSelector` 的主机列表容器设置 `maxHeight`（如 220px 或 24vh）及 `overflow: auto`
- [x] 2.3 模式选择、执行选项、执行按钮不强制固定高度，保持紧凑排列

## 3. 结果区

- [x] 3.1 将 `ExecutionResults` 放入右侧栏，占满右侧可用高度
- [x] 3.2 结果区容器设置 `overflow: auto`，内部列表/日志自行滚动，不撑开整页
- [x] 3.3 执行前右侧可为空或占位提示（如「执行后结果将显示于此」）

## 4. 样式与响应式

- [x] 4.1 统一内边距与间距，避免配置区过宽导致右侧过窄
- [x] 4.2 在 992px 断点下验证上下布局，并确认配置区高度约束仍生效
- [x] 4.3 在 1440×900、1920×1080 下验证一屏内配置与结果同屏可见

## 5. 验收

- [x] 5.1 在典型桌面分辨率下，执行前配置区完整可见，执行后结果区与配置区同屏可见
- [x] 5.2 脚本区、主机列表过长时仅内部滚动，整页不因内容过长而大幅滚动
