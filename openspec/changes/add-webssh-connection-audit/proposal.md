# Change: WebSSH 连线录像（审计连线）

## Why

运维人员通过 WebSSH 连接资产执行操作时，目前没有会话内容记录，无法事后查看「谁在何时对哪台主机做了哪些操作」，不利于安全审计与问题追溯。需要实现 **WebSSH 连线的录像记录**，便于管理员查看操作人及其终端操作内容。

## What Changes

- **录制**：在 WebSSH 会话建立后，后端对终端输出（及可选对用户输入）进行录制；会话结束时将录像数据与元数据一并持久化。
- **存储**：新增「SSH 连线记录」模型与存储（会话元数据：操作用户、目标资产、开始/结束时间、时长；录像内容：终端输出序列，可选带时间戳以便回放）。
- **列表与回放**：在「系统管理」下新增菜单 **「审计连线」**，提供连线记录列表（支持按用户、资产、时间筛选）；点击某条记录可查看/回放该次会话的终端录像。
- **权限**：仅具备「审计连线」查看权限的用户（如管理员）可访问该页面与 API。

## Impact

- **受影响规格**：新增 webssh-connection-audit 能力；可扩展现有 webssh 规格（会话结束时写入录像）。
- **受影响代码**：后端 `backend/internal/handler/websocket/ssh.go`（在 stdout/可选 stdin 流上挂载录制逻辑，会话结束时写入记录）、新增 model/repository/service/handler 与 API 路由；前端新增「审计连线」页面及路由、在 MainLayout 系统管理下增加「审计连线」菜单项；权限表增加 connection-audit:read。
