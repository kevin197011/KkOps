# Change: 运维执行页高度一屏、宽度不变、功能块布局重规划

## Why

此前对「一屏显示」的理解有偏差：实现成了左右分栏、宽度拉满。用户实际需求是：**高度占一个屏幕即可，宽度维持原来的样子**（居中、maxWidth 不变），同时**每个功能的布局再重新规划**，使整页在典型视口内高度不溢出、操作便捷。

## What Changes

- **宽度不变**：保持单栏、居中、原有最大宽度（如 maxWidth: 1200），不采用左右分栏。
- **高度一屏**：整页根容器使用视口高度（如 `minHeight: calc(100vh - 120px)`），脚本区、主机列表、结果区等长内容区域使用最大高度 + 内部滚动，使整页在典型分辨率下高度不溢出或仅最小化滚动。
- **功能块布局重规划**：在保持单栏宽度的前提下，重新规划各功能块的排布方式（如：第一行 模式选择 + 执行选项 并排；第二行 脚本区与主机区 左右并排 或 上下紧凑；执行按钮与结果区位置与高度约束），使「配置 + 执行 + 结果」在一屏高度内合理呈现。

## Impact

- **受影响规格**：execution-operator（布局相关需求，需修正为「单栏、宽度不变、高度一屏、功能块重规划」）
- **受影响代码**：`frontend/src/pages/executions/ExecutionOperatorPage.tsx`（撤销左右分栏、恢复宽度、重排功能块），以及 `components/operator/` 下各组件布局与高度相关样式
